# ADS Release: v0.4.0

## Summary
The `v0.4.0` release introduces a paradigm shift in how we handle interactive queries alongside massive stability improvements to the SQLite backend synchronization mechanism.

## Features & Improvements
- **Native Bubbletea TUI**: Added the `ads search-interactive` command which provides an interactive, full-text fuzzy-style search experience.
- **Floating Tmux Popups**: Rewired the default `Prefix + s` shortcut to trigger `tmux display-popup`, overlaying the new TUI seamlessly on top of active panes.
- **Offline Dependency Vendoring**: All external dependencies have been pulled via `go mod vendor` and tested securely offline using `-mod=vendor`.

## Bug Fixes
- **SQLITE_BUSY Drops**: Identified and resolved a severe concurrency bug where `ads search` would silently drop databases actively being written to by an `ads-recorder`. We implemented a strictly enforced `_busy_timeout=5000` combined with SQLite WAL mode to guarantee search accuracy across all active databases.

## Design Choices
- **Zero External UI Dependencies**: Chose to build the UI with `charmbracelet/bubbletea` natively compiled into the `ads` binary to eliminate requirements on user packages like `fzf`.
- **Strict Versioning Protocol**: Introduced semantic version tracking, tying minor version bumps to future bug reports and formalizing Gitflow in `AGENTS.md`.
