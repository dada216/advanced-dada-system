# ADS Release: v0.5.0

## Summary
The `v0.5.0` release focuses on UI polish and navigation functionality for the Interactive Search Pane introduced in `v0.4.0`.

## Features & Improvements
- **Clean Zsh-like Output**: Refactored the `bubbletea` search pane to strip raw terminal newlines (`\n` and `\r`) from SQLite FTS5 snippets. Search results are now perfectly flattened into single lines resembling traditional `zsh` or `fzf` history.
- **Interactive Cursor Navigation**: Implemented keyboard event handling (Up/Down arrows) to natively traverse the search results list, complete with a visual cursor tracking the selected history element.
- **Automated UI Testing**: Wrote a Tmux `send-keys` integration script (`test/test_interactive.sh`) to rigorously simulate cross-session interactive querying and UI performance under load.

## Bug Fixes
- **Newline Rendering Collapse**: Fixed a catastrophic UI rendering bug where raw newline characters within FTS snippet responses would completely break Lipgloss/Bubbletea row height bounds, causing staggering overlapping results.
