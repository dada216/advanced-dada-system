# ADS Major Release: v1.0.0

## Summary
The `v1.0.0` release introduces a massive quality of life and UX workflow improvement regarding how orchestrator sessions are handled during invocation.

## Features & Improvements
- **Auto-Initialization Workflow (`ads run`)**: 
  - When executing `ads run <session-name>`, the orchestrator now gracefully handles missing sessions instead of aborting.
  - Users are presented with a warning and an interactive, real-time prompt asking if they'd like to dynamically create the missing session.
  - Affirmative inputs (e.g., `y`, `yes`) seamlessly hook directly into the `CreateLocalSession` primitive, provision the background sqlite session, and seamlessly attach the user.
  - Negative inputs gracefully exit the application without modifying state.

## Version Bumping Context
This significant logic interception warrants the milestone bump to a stable `v1.0.0`, reflecting the CLI's maturation into a robust, interactive utility.
