# ADS Release: v1.1.0

## Summary
The `v1.1.0` release addresses usability requests for the Interactive Search Pane, greatly accelerating the workflow for locating and reusing commands.

## Features & Improvements
- **Real-Time Prefix Matching**: Upgraded the `ads search` engine FTS5 queries to automatically wrap query tokens in double quotes and append the wildcard (`*`) suffix (`"query"*`). This guarantees real-time visual results as the user types partial tokens (e.g., matching `piripi` when typing `piri`), eliminating the wait for a fully formulated word.
- **Tmux Clipboard Integration**: Bound the `Enter` key inside the Interactive Search UI to automatically isolate the selected row snippet, strip internal red highlight ANSI sequences (`\033[31m`, `\033[0m`), and seamlessly inject it into the Tmux clipboard buffer via `tmux set-buffer`. The exact selected history entry is now instantly ready to paste into the active session via `Prefix + ]`.
