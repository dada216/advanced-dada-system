# ADS Release: v1.2.0

## Summary
The `v1.2.0` release addresses a critical input bug in the Interactive Search pane where arrow key navigation was failing due to Bubbletea terminal strictness, and introduces Vim/Emacs keybindings for power users.

## Features & Improvements
- **Robust Keyboard Capture**: Swapped out the strict `msg.Type` event listener for a more robust `msg.String()` mapping. This ensures arrow keys function perfectly regardless of how the host terminal emulator (or Tmux) interprets application cursor modes.
- **Power User Keybindings**: You can now navigate the search results list dynamically using standard Vim (`Ctrl+J` / `Ctrl+K`) and Emacs (`Ctrl+N` / `Ctrl+P`) hotkeys in addition to the standard up/down arrows.
- **System binary installation**: Re-ran `sudo make install` to ensure the compiled system binary natively receives all new UX improvements directly at `/usr/bin/ads`.
