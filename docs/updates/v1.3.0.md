# ADS Release: v1.3.0

## Summary
The `v1.3.0` release focuses strictly on polished UI feedback mechanisms for the interactive search pane, significantly enhancing visibility during search operations.

## Features & Improvements
- **Full-Row Highlighting**: Modified the Bubbletea `lipgloss` rendering logic to dynamically expand the selected row's background color. Instead of terminating at the end of the text string, the selection highlight now spans the entire dynamic width of the terminal window, creating a highly visible, professional selection bar.
- **Tmux Action Feedback**: When selecting a result using `Enter`, the application now natively hooks into `tmux display-message`. After the popup closes, a non-intrusive status message flashes at the bottom of the user's host Tmux session explicitly verifying the exact snippet that was copied to their clipboard (e.g., `ADS Copied: echo 'hello'...`). Canceling via `Esc` cleanly exits without feedback.
