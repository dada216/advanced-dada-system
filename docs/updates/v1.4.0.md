# ADS Release: v1.4.0

## Summary
The `v1.4.0` release implements a minor duration bugfix to the Tmux feedback system.

## Features & Improvements
- **Extended Feedback Duration**: The native `tmux display-message` command has been augmented with the `-d 3000` parameter. Feedback toasts indicating a successful clipboard copy now linger for 3 full seconds rather than disappearing instantaneously, greatly improving legibility.
