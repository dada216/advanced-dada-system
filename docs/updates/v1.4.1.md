# ADS Release: v1.4.1

## Summary
The `v1.4.1` release implements a minor pacing tweak to the Tmux feedback system to optimize the user experience.

## Features & Improvements
- **Optimized Feedback Duration**: The native `tmux display-message` notification duration has been refined from 3 seconds down to 2 seconds (`-d 2000`). This ensures the clipboard confirmation is highly readable but clears away fast enough to not feel intrusive.
