# ADS Release: v1.5.0

## Summary
The `v1.5.0` release implements a comprehensive aesthetic overhaul of the interactive search pane to seamlessly blend with native Tmux environments.

## Features & Improvements
- **Native Tmux Aesthetics**: Stripped out the original vibrant pink/blue lipgloss style palette and replaced it with classic, muted terminal colors. 
  - The popup title now perfectly mimics the default Tmux status bar (Green background, Black text).
  - The cursor and session tags use standard terminal bright-greens and yellows.
  - The selection background now uses a muted dark gray (`238`) that cleanly integrates into standard console themes without looking like an external UI intrusion.
