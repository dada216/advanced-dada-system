# ADS Release: v1.6.0

## Summary
The `v1.6.0` release introduces a structural layout overhaul to the interactive search pane rows alongside a significant upgrade to search result clarity.

## Features & Improvements
- **Full Line Extraction**: Replaced the FTS5 `snippet()` function with the native `highlight()` function in the SQLite query engine. Instead of awkwardly truncating text to a 10-token window, search results now consistently return and display the *entire* text line with the target keyword highlighted via ANSI escape sequences.
- **Split Layout Alignment**: The row display logic was rewritten using exact Lipgloss mathematical terminal widths. The session name and matched text line are anchored cleanly to the left edge, while the `(row X)` indicators are strictly aligned and flushed against the far right edge of the terminal. This produces a perfectly organized, highly readable, two-column visual hierarchy.
