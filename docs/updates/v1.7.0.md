# ADS Release: v1.7.0

## Summary
The `v1.7.0` release polishes the visual rendering of the search pane by mitigating layout overlaps and introducing high-contrast active-row highlighting.

## Features & Improvements
- **Terminal Control Character Stripping**: Upgraded `cleanSnippet()` to aggressively strip unescaped Tab (`\t`) and Backspace (`\b`) control characters that sneak through from the terminal environment into the SQLite `fts_index`. This guarantees that Lipgloss terminal width calculations are 100% accurate, completely eliminating the bug where session names would randomly overlap onto matched text strings.
- **High-Contrast Row Highlighting**: Updated the active row selection background from a muted dark gray to a vibrant, high-contrast light green (`119`) with dark text (`232`). This color persists dynamically across the entire calculated width of the terminal (`m.width`), creating an unmissable selection bar that clearly separates the active row from surrounding text.
