# ADS Release: v1.7.1

## Summary
The `v1.7.1` release resolves an issue where the background highlight for the selected interactive search row was prematurely cutting off before the end of the line, and tones down the brightness of the selection color.

## Features & Improvements
- **Continuous Highlight Rendering**: Bypassed Bubbletea's native `.Width()` styling engine in favor of explicitly intercepting internal ANSI escape codes. The renderer now dynamically replaces any style reset `\033[0m` that occurs *within* the selected row with a renewed background-color sequence (`\033[0m\033[48;5;22m`). This guarantees an unbroken, edge-to-edge color bar that spans the entire physical terminal width.
- **Muted Aesthetic Highlight**: Reduced the background highlight color from a high-brightness light green (`119`) to a significantly darker, muted ANSI terminal green (`22`), making extended reading sessions substantially more comfortable.
