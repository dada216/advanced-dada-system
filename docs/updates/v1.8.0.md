# ADS Release: v1.8.0

## Summary
The `v1.8.0` release maps the interactive search pane to a lightning-fast global keybind, dropping the need to press the Tmux prefix.

## Features & Improvements
- **Global Search Keybinding**: Replaced the default `Prefix + s` shortcut with a native `-n C-s` (`Ctrl+S`) keybind in the default session templates. This allows users to globally invoke the interactive history search popup at any point in any session instantly, without needing to input the standard `Ctrl+B` Tmux prefix first.
