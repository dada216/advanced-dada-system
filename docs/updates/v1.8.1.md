# ADS Release: v1.8.1

## Summary
The `v1.8.1` release fixes an issue where the new global `Ctrl+S` keybinding introduced in `v1.8.0` was not being applied to previously active sessions.

## Features & Improvements
- **Hot-Reload Session Attachments**: In `v1.8.0`, the new default configuration was successfully updated in the SQLite `meta.db` database, but the `ads run` orchestrator was not actively injecting updated profiles into existing background Tmux sessions. We refactored `internal/orchestrator/run.go` to unconditionally extract, render, and execute `tmux source-file` for every single session attachment. Now, when a user re-attaches to any session, the Tmux server guarantees that all bindings, including the new global `Ctrl+S` search shortcut, are instantly hot-reloaded and active without requiring a session restart.
