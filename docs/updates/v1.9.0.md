# ADS Release: v1.9.0

## Summary
The `v1.9.0` release maps the Tmux paste command to a global keybind, dropping the need to press the Tmux prefix to extract text from the interactive search pane.

## Features & Improvements
- **Global Paste Keybinding**: Replaced the default `Prefix + ]` paste shortcut with a native `-n C-]` (`Ctrl+]`) keybind in the default session templates. Once a search result is copied to the Tmux buffer via `Ctrl+S`, users can immediately deploy the copied text into their active session by hitting `Ctrl+]` without touching the Tmux prefix.
