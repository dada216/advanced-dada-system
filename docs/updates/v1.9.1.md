# ADS Release: v1.9.1

## Summary
The `v1.9.1` release resolves an issue where invisible ANSI escape sequences (specifically those used to enable Bracketed Paste Mode) leaked into the SQLite Full-Text Search database and were subsequently surfaced as raw junk text (`2004lkubernetes`) when copying lines out of remote sessions.

## Bugfixes
- **Bracketed Paste Stripping**: The ANSI extraction regex in `internal/ansi/strip.go` was upgraded to intercept CSI sequences containing the `?` intermediate byte (such as `\x1b[?2004h`). This ensures all future recordings accurately purge invisible terminal modes.
- **Retroactive Data Cleaning**: Refactored the interactive search copy command to universally enforce `ansi.Strip()` upon the payload right before pushing it into the host clipboard. This acts as an immediate hotfix for all past recordings whose databases still contain unstripped legacy ANSI, allowing them to be copied without corruption.
