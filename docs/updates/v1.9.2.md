# ADS Release: v1.9.2

## Summary
The `v1.9.2` release fixes a layout bug in the interactive search results pane where multiline chunks retrieved from the FTS engine were flattened into a single line, causing shell prompts and command outputs to bleed together in confusing orders.

## Bugfixes
- **Search Snippet Line Isolation**: Previously, if a raw terminal read chunk contained both a command's output and the subsequent shell prompt, the `cleanSnippet` formatter simply replaced all newlines with spaces. This merged the lines side-by-side. The formatter has been upgraded to intelligently split the chunk by newline boundaries, scan for the FTS red highlight marker (`\033[31m`), and extract *only* the specific terminal line that triggered the match. This perfectly isolates the matched command or output string, dropping the un-matched adjacent prompts.
