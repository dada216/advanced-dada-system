# ADS Release: v2.0.0

## Summary
The `v2.0.0` release introduces a foundational metadata layer for Tmux profiles and Sessions, paving the way for advanced federated search filtering capabilities. Additionally, the project's internal structure has been reorganized to support the scale of these new features.

## Features & Improvements
- **Profile Metadata**: `tmux_profiles` can now be tagged with `customer`, `server`, and `project` metadata fields.
- **Interactive Editor**: Added the `ads edit <profile-name>` command. This launches an interactive prompt to modify a profile's metadata. Leaving a field completely blank unsets it (setting it to `NULL`).
- **Session Injection**: Upon running a session via `ads run`, the orchestrator now directly injects the profile's active metadata into the isolated `sessions/<uuid>.db` database, writing it to a new `metadata` table. This ensures recorded sessions retain their contextual metadata even if the overarching `meta.db` profile is later changed or if the database is moved to another machine.

## Internal Refactoring
- Restructured `internal/meta` package. Database logic has been cleanly split across `db.go`, `session.go`, and `profile.go` to maintain readability as the codebase expands.
