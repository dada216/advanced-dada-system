# ADS Release: v2.0.1

## Summary
The `v2.0.1` release improves the user experience of the new metadata editor by providing helpful error messages when a user accidentally attempts to edit a session name instead of a profile name.

## Bugfixes & UX Improvements
- **Smart Error Routing in `ads edit`**: If a user runs `ads edit <name>` and the name corresponds to a Session rather than a Profile, the CLI will intercept the error, look up the Session, and print a targeted message indicating which Profile that Session uses, along with the exact command needed to edit it.
