# ADS Release: v2.1.0

## Summary
The `v2.1.0` release completes the metadata infrastructure introduced in v2.0.0 by providing the necessary CLI commands for users to freely create new profiles and migrate existing sessions to different profiles.

## Features & Improvements
- **Profile Management**: Introduced the `ads profile` command suite. 
  - `ads profile new <name>` creates a new profile by automatically cloning the default tmux configuration.
  - `ads profile list` outputs a tabulated summary of all your profiles along with their configured metadata (`customer`, `server`, `project`).
- **Session Migration**: Added the `ads update <session-name> --profile <profile-name>` command. This allows users who have already recorded sessions under the `default` profile to re-attach those sessions to newly created custom profiles. Next time the session is run, the new profile's configuration and metadata will be seamlessly injected.
