# ADS Release: v2.1.1

## Summary
The `v2.1.1` release improves visibility by surfacing the newly added Profile information directly within the standard `ads list` command, and updates the documentation man pages to reflect all the new v2 features.

## Improvements
- **Profile Column added to `ads list`**: The primary session listing command now explicitly displays which Profile is assigned to each session. This makes it instantly clear whether a session is running under `default` or a custom profile, without having to inspect the database.
- **Man Page Update**: The `docs/ads_doc` manual page has been updated to cover the `ads profile`, `ads edit`, and `ads update` commands, and its footer was bumped to `ADS 2.1`.
