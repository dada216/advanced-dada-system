# ADS Release: v2.2.0

## Summary
The `v2.2.0` release directly addresses user feedback regarding the default tmux scroll behavior and introduces the ability to manually edit raw tmux configurations via the CLI.

## Bugfixes & Improvements
- **Native Scrolling**: Removed brittle, hardcoded `WheelUpPane` bindings from the `default` profile. Replaced them with native `copy-mode-vi` scrolling commands that correctly reverse the scroll direction to feel more natural and fluid.
- **Infinite History**: Increased the `history-limit` in the `default` profile from `100,000` to `999,999,999` (practically infinite).
- **Configurable Profiles (`ads profile edit-config`)**: Implemented a new command `ads profile edit-config <profile-name>`. This command pulls the raw tmux template text from the SQLite database, opens it in your default `$EDITOR` (e.g., `vim`, `nano`), and seamlessly saves the changes back. This gives users absolute control over their tmux environments without writing raw SQL.
- **Safe Migrations**: Updated the orchestrator's initialization logic to ensure it doesn't overwrite your `default` profile if you have already manually customized it.
