# ADS Release: v2.2.1

## Summary
The `v2.2.1` release fixes an over-correction in the previous release regarding scroll direction.

## Bugfixes
- **Standard Scrolling Restored**: Removed the reverse mouse scrolling bindings that were erroneously introduced in v2.2.0. The `default` profile now exclusively relies on tmux's native scrolling behavior (`set -g mouse on`), which inherently respects standard OS-level scroll wheel direction (wheel up = scroll history up).
