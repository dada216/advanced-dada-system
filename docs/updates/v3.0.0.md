# ADS Release: v3.0.0

## Summary
The `v3.0.0` release introduces a massive architectural overhaul. ADS now officially supports a decentralized plugin system powered by `hashicorp/go-plugin`. Heavy analytical and query tasks have been extracted out of the core orchestrator into isolated binaries communicating over fast, local RPC sockets. 

## Features & Improvements
- **Plugin Infrastructure**: Built the `internal/plugin` core that defines the universal RPC interfaces for ADS plugins.
- **Search as a Service**: The federated FTS5 search engine has been completely extracted into a standalone plugin binary (`ads-plugin-search`). The core `ads search` and `ads search-interactive` commands now dynamically spin up this plugin to execute the queries over RPC.
- **LLM OpenRouter Integration**: Introduced a brand new `ads-plugin-llm` and the accompanying `ads llm` command suite.
  - `ads llm summarize <session>`: Uses OpenRouter (`openai/gpt-3.5-turbo`) to analyze the terminal history and generate a high-level summary of the session's events and errors.
  - `ads llm ask <session> "<question>"`: Queries the LLM regarding specific context from a recorded session.
  - *Note:* Requires an OpenRouter API key saved to `~/.local/share/ads/secrets/openrouter.key` or exported as the `ADS_OPENROUTER_KEY` environment variable.
- **Makefile Expansion**: The build and installation pipelines have been updated to compile and distribute the new plugin binaries alongside the core tools.
