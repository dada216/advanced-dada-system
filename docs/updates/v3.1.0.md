# ADS Release: v3.1.0

## Summary
The `v3.1.0` release introduces interactive plugin configuration via the CLI. It allows users to securely set and manage plugin-specific settings directly within the `ads` Orchestrator, storing them in the SQLite `meta.db`.

## Features
- **Plugin Command Suite (`ads plugin`)**: Added new commands to manage plugin settings.
- **Interactive OpenRouter Configuration (`ads plugin edit llm`)**: 
  - Instead of manually editing text files or setting environment variables, users can now run `ads plugin edit llm` to interactively input their OpenRouter API key.
  - Upon receiving the key, the CLI connects to OpenRouter to dynamically fetch and list all available AI models.
  - The user can then select their desired model directly from the terminal.
  - Both the API key and the selected model are securely saved to the `plugin_configs` table in `meta.db`.
- **Plugin Settings Inspector (`ads plugin list llm`)**: Users can view their currently configured API key (masked for security) and selected AI model at a glance.
- **Dynamic LLM Plugin**: The `ads-plugin-llm` binary has been upgraded to read its configuration dynamically from `meta.db` (falling back to legacy environment variables or text files if needed).
