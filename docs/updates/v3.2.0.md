# ADS Release: v3.2.0

## Summary
The `v3.2.0` release introduces usability improvements to the Search Plugin results. The user interface now displays the chronological date of the terminal output instead of the raw database row ID, providing much better context when reviewing historical logs.

## Features & Improvements
- **Chronological Search Results**: 
  - The `internal/search` engine now performs a SQL `JOIN` between the `fts_index` and `io_stream` tables to pull the exact `ts` (timestamp) of every matched line.
  - The results are returned and strictly sorted by Date (most recent first) globally across all queried sessions.
  - The `ads search` CLI and the `ads search-interactive` TUI popup have both been updated to display the formatted date `(YYYY-MM-DD HH:MM:SS)` on the right-hand side of each snippet, replacing the arbitrary row number.
