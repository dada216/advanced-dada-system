# ADS Release: v3.3.0

## Summary
The `v3.3.0` release fully wires up the `ads llm` commands to dynamically retrieve context from your recorded SQLite session databases, solving the issue where queries were previously blind to the actual session history.

## Features & Improvements
- **Context-Aware LLM Analytics**:
  - The `ads llm summarize <session>` and `ads llm ask <session> "<query>"` commands now actively connect to the `meta.db` and the corresponding `<uuid>.db` session database.
  - They automatically fetch the chronological text from the `fts_index` (up to 200 recent chronological lines).
  - This terminal history is dynamically appended to your OpenRouter API payload, allowing the selected AI model to accurately read and analyze the actual events, errors, and text from the session before responding.
