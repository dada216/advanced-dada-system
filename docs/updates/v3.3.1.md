# ADS Release: v3.3.1

## Summary
The `v3.3.1` release resolves an issue in the `ads plugin edit llm` configuration flow where users selecting an OpenRouter model via its integer menu ID would incorrectly send the raw integer directly to the OpenRouter API, leading to a HTTP 400 error.

## Bug Fixes
- **Model ID Resolution**: The interactive configuration command (`cmd/ads/plugin.go`) now correctly detects when a user enters an integer to select a model from the list. It accurately maps the integer back to the string ID (e.g., `openai/gpt-3.5-turbo`) before saving the configuration to the SQLite `meta.db`.
