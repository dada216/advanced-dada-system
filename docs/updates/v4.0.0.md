# ADS v4.0.0 "Pangolin" — Release Notes

## Release Type: Major

**Branch:** `pangolin`
**Version:** `v4.0.0`
**Codename:** Pangolin
**Status:** In Development

---

## Summary

v4.0.0 is a full architectural rewrite. The tmux-based capture pipeline
is replaced with a transparent PTY proxy (`ads-shell`) that integrates
natively with Konsole on KDE/Fedora 44. The HashiCorp go-plugin system
is dropped in favor of direct function calls. Remote session management
is removed. A full-featured TUI dashboard (`ads-tui`) replaces the
search-only interactive mode.

## What Changed

### Architecture
- **Capture**: tmux `pipe-pane` → PTY proxy (`ads-shell` binary)
- **Session model**: Managed tmux sessions → ephemeral Konsole tabs
- **Plugins**: HashiCorp go-plugin (4 binaries) → 3 focused binaries, direct calls
- **Remote sessions**: Dropped as a managed concept — users run `ssh` inside recorded sessions
- **Session continuation**: New session with `parent_uuid` foreign key, separate `.db` per segment

### Binaries
- `ads` — CLI orchestrator (streamlined, fewer commands)
- `ads-shell` — PTY proxy recorder with inline session picker (replaces `ads-recorder`)
- `ads-tui` — Full dashboard TUI: sessions, search, profiles, settings (replaces `search-interactive` subcommand)
- **Removed**: `ads-recorder`, `ads-plugin-search`, `ads-plugin-llm`

### Data Model
- **New table**: `input_stream` — records user keystrokes (bidirectional capture)
- **New table**: `session_info` — environment snapshot at session start
- **New column**: `sessions.parent_uuid` — links continuation sessions
- **New column**: `sessions.sealed_at` — timestamp of session close
- **Simplified**: `profiles` table (metadata only, no tmux config)
- **Renamed**: `plugin_configs` → `llm_config`

### Dependencies
- **Added**: `creack/pty` (PTY allocation)
- **Removed**: `hashicorp/go-plugin`, `hashicorp/go-hclog`, `hashicorp/yamux`, `google.golang.org/grpc`, `google.golang.org/protobuf`
- **Removed**: Runtime dependency on `tmux`

### CLI Surface
- **New**: `ads konsole install`, `ads konsole remove`
- **New**: `ads llm config` (replaces `ads plugin edit llm`)
- **Changed**: `ads run` opens Konsole tab in background (foreground fallback)
- **Changed**: `ads search` supports `--json` flag
- **Changed**: `ads list` shows segment count and last active time
- **Removed**: `ads auth test`, `ads update`, `ads plugin *`, `ads search-interactive`, `ads profile edit-config`

### Quality
- Sentinel errors in `internal/meta` (no more string matching)
- Signal handling in `ads-shell` (clean shutdown on SIGTERM/SIGHUP)
- Buffered SQLite writer (batched commits instead of per-chunk transactions)
- Improved ANSI stripper (DCS sequences, C0 controls, SS2/SS3)
- Concurrent federated search
- Typed structs for OpenRouter API responses
