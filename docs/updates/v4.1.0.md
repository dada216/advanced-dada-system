# Version 4.1.0 Update (Zsh Compatibility Fix)

## Improvements & Bugfixes
- **Dynamic User Shell Parsing**: The `ads-shell` PTY proxy was updated to determine the user's primary shell automatically using the `$SHELL` environment variable instead of hardcoding `bash`. This provides native support for `zsh`, `fish`, or any other configured user shell.
- **Zsh Semantic Shell Hook Support**: The `ads hook` command has been expanded to support `zsh`. It dynamically loads zsh's `add-zsh-hook` to bind the pre-command (`precmd`) and pre-execution (`preexec`) events, correctly injecting OSC 133 semantic chunks around prompts and commands without corrupting Zsh's rich `$PROMPT` state.
- **Konsole Profile Initialization Fix**: Updated `install-konsole.sh` to construct the internal `Command=` attribute utilizing the universally compliant `sh -c` rather than explicitly relying on `bash`, ensuring out-of-the-box compatibility on non-Bash environments.
- **Bug tracking**: Addressed the hardcoded Bash limitation documented in `docs/bugs/zsh-support.md`.
