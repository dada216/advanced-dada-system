# Version 4.10.0 Update (Automated Shell Integration)

## Improvements & Bugfixes
- **Automated Hook Installation (`ads hook install`)**: Added a highly requested CLI feature to solve the "empty command history" problem. Since `ads` requires your interactive shell to emit OSC 133 semantic markers to capture clean keystrokes, you previously had to manually configure your RC files. Now, you can simply run `ads hook install zsh` or `ads hook install bash`, and it will safely inject the exact `eval` script directly into your `~/.zshrc` or `~/.bashrc` file automatically!
- **Bug tracking**: Resolved according to the specifications in `docs/bugs/hook-install.md`.
