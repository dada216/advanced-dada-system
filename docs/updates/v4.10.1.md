# Version 4.10.1 Update (Zsh Hook Fix)

## Improvements & Bugfixes
- **Fixed Zsh Keystroke Interception**: Resolved a critical issue where the `command_history` database table remained empty for Zsh users even after successfully installing the semantic hooks. The Zsh `$PROMPT` variable was treating the OSC 133 `B` marker (Start of Input) as literal text instead of an invisible escape sequence, meaning the parser's state machine was never receiving the necessary trigger to begin recording keystrokes. The hook logic has been corrected to use ANSI-C quoting (`$'\e'`), ensuring 100% accurate byte evaluation.
- **Bug tracking**: Resolved according to the specifications in `docs/bugs/zsh-prompt-eval.md`.
