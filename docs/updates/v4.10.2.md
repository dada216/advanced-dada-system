# Version 4.10.2 Update (Zsh Theme Compatibility)

## Improvements & Bugfixes
- **Fixed Zsh Theme Interference**: Addressed a critical bug where advanced Zsh themes (like `starship` or `powerlevel10k`) were dynamically overwriting the `$PROMPT` variable on every cycle, erasing the OSC 133 `B` semantic marker required for `ads-shell` history tracking. The hook logic has been refactored to dynamically inject the `B` marker directly inside the `precmd` lifecycle hook with an idempotency check. Because the `ads` hook registers last, it guarantees the marker survives any theme modifications, fully restoring `command_history` functionality for all Zsh power users.
- **Bug tracking**: Resolved according to the specifications in `docs/bugs/zsh-theme-overwrite.md`.
