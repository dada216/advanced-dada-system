# Version 4.10.3 Update (Foolproof Zsh History)

## Improvements & Bugfixes
- **Foolproof Zsh Command Extraction**: Addressed a critical and complex edge-case where the Zsh Line Editor (ZLE) would trigger a transient prompt redraw upon pressing `Enter`, unintentionally erasing the PTY keystroke buffer right before execution. `ads-shell` has been upgraded to support a non-standard OSC 133 extension, allowing Zsh's `preexec` hook to pass the exact command string directly inside the `C` marker payload. This entirely eliminates the PTY guessing heuristic for Zsh users, ensuring 100% accurate, flawless command history capture regardless of terminal resizes, autosuggestions, or transient themes.
- **Bug tracking**: Resolved according to the specifications in `docs/bugs/zsh-zle-redraw.md`.
