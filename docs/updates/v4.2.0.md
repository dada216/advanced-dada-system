# Version 4.2.0 Update (Shell Login Environment & Fallback)

## Improvements & Bugfixes
- **Login Shell Initialization**: Fixed a critical bug where `ads-shell` was launching non-login shell instances (e.g. `bash` or `zsh` instead of `-bash` or `-zsh`). This caused user profiles (`~/.zprofile`, `~/.bash_profile`) to be skipped upon launching an ADS Konsole profile. The proxy now properly manipulates `argv[0]` to prepend `-`, identical to native terminal emulators, ensuring all user environments and aliases are loaded immediately.
- **/etc/passwd Shell Fallback**: In environments where the `SHELL` environment variable might not be exported correctly by the display manager or when invoked programmatically, `ads-shell` now gracefully falls back to querying the user's explicit default shell from `/etc/passwd`.
- **Bug tracking**: Resolved the missing login environment issue outlined in `docs/bugs/zsh-login-shell.md`.
