# Version 4.2.1 Update (Konsole Quoting & Shell Execution Regression)

## Improvements & Bugfixes
- **Native `ads launch` Command**: Added a dedicated `ads launch` subcommand that automatically generates a unique session ID (e.g., `ads-<timestamp>`), registers it in the SQLite metadata db, and immediately runs it. This cleanly bypasses the need for fragile `sh -c` quoting inside the Konsole profile GUI.
- **Reverted Login Shell Injection**: Standard Linux terminal emulators (like KDE Konsole) spawn interactive non-login shells by default. The previous update forced login shells (e.g. `-bash`), which accidentally bypassed users' `~/.bashrc` configs. This has been reverted, ensuring `.bashrc` and `.zshrc` execute natively, respecting users who bootstrap Zsh via Bash rc files.
- **Konsole Profile Simplification**: The `make install-konsole` target now registers `Command=/usr/bin/ads launch`, making it significantly safer and fully resilient to GUI quote normalization.
