# Version 4.2.2 Update (Native Shell Resolution Priority Fix)

## Improvements & Bugfixes
- **Prioritized OS Identity over Env Vars**: Fixed a logic bug where `ads-shell` checked the `$SHELL` environment variable *before* parsing the system's `/etc/passwd` file. If a display manager or parent terminal emulator explicitly exported `SHELL=/bin/bash`, `ads-shell` was tricked into using `bash` instead of the user's natively configured shell (like `zsh`).
- **`getent passwd` Support**: Improved the shell resolution engine to proactively query `getent passwd` before falling back to manual `/etc/passwd` file parsing. This guarantees native compatibility with enterprise/networked authentication systems (LDAP, ActiveDirectory, NIS, systemd-homed) where local `/etc/passwd` files might be missing or incomplete.
- **Bug tracking**: Addressed the persistent bash drop-in bug documented in `docs/bugs/ads-shell-getent.md`.
