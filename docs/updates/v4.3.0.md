# Version 4.3.0 Update (Explicit Shell Overrides)

## Improvements & Bugfixes
- **First-Class CLI Shell Overrides**: Introduced a new `--shell` flag across `ads run`, `ads launch`, and the internal `ads-shell` proxy. This massive quality-of-life feature empowers users to explicitly bypass their OS-level `/etc/passwd` identity, allowing them to instantly launch a custom shell (e.g. `zsh`, `fish`) on a per-session basis without modifying their host OS account configurations.
- **Konsole Profile Specialization**: The Konsole KDE shortcut generator (`install-konsole.sh`) now explicitly injects `--shell zsh` directly into the `Command=` directive. This ensures that users who desire a dedicated Zsh environment receive it instantly upon opening a tab, completely sidestepping standard bash-based initialization sequences.
- **Bug tracking**: Addresses the hardcoded identity limitation filed in `docs/bugs/explicit-zsh-override.md`.
