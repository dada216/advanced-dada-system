# Version 4.4.0 Update (Session Management UX)

## Improvements & Bugfixes
- **Context-Aware `ads list`**: Transformed the output of the `ads list` command to drastically improve user experience. The command now visually tags the currently active session with a `*` flag by matching against the local `$ADS_SESSION` environment footprint. Furthermore, auto-generated sessions (such as the default `ads-<timestamp>` ones) are neatly decoupled into an isolated "Auto-Generated (Unnamed) Sessions" table to reduce clutter across named workflows.
- **Native `ads rename` Tool**: Introduced a streamlined `ads rename <new-name>` command. This allows users inside dynamically generated sessions to retrospectively grant their current workspace a memorable semantic name directly through the SQLite metadata store without halting the orchestration.
- **Bug tracking**: The management pain-points were resolved according to `docs/bugs/session-management.md`.
