# Version 4.5.0 Update (JSON Search Interface)

## Improvements & Bugfixes
- **Programmatic Search API**: We have introduced a `--json` flag to the `ads search` command. This enables completely automated, machine-readable workflows by intercepting the FTS5 federated query results and serializing them into cleanly indented JSON arrays. This is immensely powerful for piping output into tools like `jq` or external LLM scripts without having to parse unstructured terminal text output.
- **Bug tracking**: Implemented as requested in `docs/bugs/search-json.md`.
