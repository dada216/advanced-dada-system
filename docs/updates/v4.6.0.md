# Version 4.6.0 Update (Bulk Session Deletion)

## Improvements & Bugfixes
- **Globbing Support for Deletions**: Upgraded the `ads delete` command to natively support shell globbing patterns (e.g., `*`, `?`, `[]`). You can now execute bulk cleanup workflows like `ads delete "ads-*"` to instantly wipe out all automatically generated sessions without having to copy-paste exact UUIDs or names. Exact string matching is still fully preserved for single-session targeted deletions.
- **Bug tracking**: Implemented as requested in `docs/bugs/delete-globbing.md`.
