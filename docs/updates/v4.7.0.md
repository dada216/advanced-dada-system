# Version 4.7.0 Update (OSC Scanner Rewrite)

## Improvements & Bugfixes
- **Fixed `command_history` Extraction & Memory Leak**: Re-engineered the semantic chunking engine. The previous regex-based implementation suffered from a buffer starvation bug when exposed to standard ANSI formatting sequences (like Zsh syntax highlighting), completely halting `command_history` population and leaking memory. The new engine is a robust, O(N) native byte scanner that elegantly handles partial terminal sequences without dropping data or bloating RAM.
- **Bug tracking**: Resolved according to the analysis in `docs/bugs/osc-scanner-leak.md`.
