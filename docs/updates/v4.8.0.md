# Version 4.8.0 Update (Global Configuration Architecture)

## Improvements & Bugfixes
- **Stateful Global Config**: Deployed a fully persistent JSON configuration layer stored safely in `~/.local/share/ads/config.json`.
- **`ads config` CLI**: Introduced the powerful new `ads config` command. You can now permanently enforce a custom shell architecture natively (e.g., `ads config default_shell zsh`). This completely solves the stateless nature of the `--shell` flag, meaning any time you manually invoke `ads run <session>` from another terminal, it will instantly respect your global `zsh` preference without needing explicit flags!
- **Bug tracking**: Resolved according to the analysis in `docs/bugs/global-config.md`.
