# Version 4.8.1 Update (Clean Command History)

## Improvements & Bugfixes
- **Fixed Dirty Command History Extraction**: Fixed a major bug in the `ads hook` generation where the shell's prompt text (e.g., `user@host$ `) was leaking into the `command_history` database records. The OSC 133 `B` (Start of Input) semantic marker is now correctly injected at the *end* of the prompt string rather than the beginning, ensuring 100% clean keystroke extraction.
- **Permanent Regression Test**: Added a robust end-to-end PTY integration test suite (`db_test.go`) to prevent this logic from ever regressing.
- **Bug tracking**: Resolved according to the analysis in `docs/bugs/dirty-history.md`.
