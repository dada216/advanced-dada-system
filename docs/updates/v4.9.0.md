# Version 4.9.0 Update (Session DB Path Export)

## Improvements & Bugfixes
- **`ads list` UI Enhancement**: The `ads list` command now natively resolves and prints the full absolute filepath to the underlying SQLite session database in a new `DB PATH` column. This makes it significantly easier to open specific sessions in external SQLite GUIs (like DBeaver) for raw data inspection without having to manually reconstruct UUID paths.
- **Bug tracking**: Resolved according to the feature specifications in `docs/bugs/list-db-path.md`.
