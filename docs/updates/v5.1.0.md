# ADS v5.1.0 Release Notes

## Bugfixes and Data Integrity Improvements
- **Command Output Capture (`v5.1_command_history_incomplete.md`)**:
  - The core recording schema in `internal/sessiondb/db.go` has been extended to include an `output_text` column in the `command_history` table.
  - The `ansi.OSCScanner` logic has been enhanced to actively buffer and isolate the raw stdout chunks flowing between the `C` (execution start) and `D` (execution end) semantic markers.
  - Command output is now precisely mapped and recorded directly alongside its parent command text in the database, closing the gap where `io_stream` raw bytes were previously orphaned from their conceptual `command_history` rows.

## Maintenance
- **Native RPM Packaging**: Established robust automated `make rpm` and `upgrade.sh` scaffolding for fast, deterministic deployment of updates.
- **Enhanced Test Matrix**: Fully integrated explicit `stdin`/`stdout` direction tracking tests and Zsh-specific PTY hooks testing into the automated test suite.
