# ADS v5.2.0 Release Notes

## Features
- **KDE Plasma & Fedora 44 Desktop Integration**:
  - The RPM package now fully implements system-level desktop integration specifically targeted at KDE Plasma environments.
  - A global `ads.desktop` entry is automatically installed to `/usr/share/applications/`, making the Advanced Dada System searchable and launchable directly via KRunner, Kickoff, and other Application Launchers.
  - A global KDE Konsole profile (`ADS.profile`) is securely deployed to `/usr/share/konsole/ADS.profile` and instantly available to all users.
  - Bash and Zsh auto-completion scripts are natively generated via Cobra CLI (`ads completion`) during the package build process and natively installed into their respective system completion directories (`/usr/share/bash-completion/completions/ads` and `/usr/share/zsh/site-functions/_ads`).
