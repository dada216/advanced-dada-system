# ADS v5.2.1 Release Notes

## Bugfixes
- **Schema Migration (`output_text`)**:
  - Addressed a critical bug introduced in `v5.1.0` where existing user databases (created in `v5.0` or earlier) would throw an error (`table command_history has no column named output_text`) upon running `ads run` or `ads-shell`.
  - Added an automatic schema migration hook to `internal/sessiondb/db.go` that explicitly detects the missing `output_text` column using `pragma_table_info` and safely injects it via `ALTER TABLE` upon opening the SQLite session database.
