# ADS v5.2.2 Release Notes

## Automation & Testing
- **E2E Diagnostic Ping**:
  - Introduced a hidden CLI command `ads test-diagnostic [data]` specifically built to support strictly automated, autonomous pipeline testing. 
  - Allows host execution pipelines to inject verifiable semantic markers into the terminal stream without polluting user-facing documentation.
- **Autonomous E2E Script**:
  - Shipped `scripts/e2e-pipeline.sh` which exercises the full autonomous D-Bus execution pipeline. It provisions a session via `ads new`, injects the `test-diagnostic` command via the native `ads run` PTY, and federated-queries the SQLite backend to computationally verify that the recording boundary remains unbroken.
