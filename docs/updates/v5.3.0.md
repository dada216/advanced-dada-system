# ADS v5.3.0 Release Notes

## LLM Ingestion Architecture
- **Configurable History Extraction**:
  - Abstracted session history extraction into the `internal/llmformat` package.
  - Implemented the `Formatter` interface to allow history to be serialized dynamically based on the target LLM's structural needs.
- **Semantic Format**:
  - The default formatter is now `SemanticFormatter`. Instead of sending a raw chronology of terminal bytes, it securely queries the structured `command_history` SQLite table.
  - Formats data into pristine chunks: `User Command`, `Exit Code`, and `Output`. This drastically reduces token noise (e.g. backspaces, re-draws, excessive newlines) and optimizes the context window for accurate summarization.
- **JSON Format**:
  - Added a `JSONFormatter` implementation. Perfect for function-calling LLMs or autonomous agents that ingest the history natively as structured `[]SessionEvent` arrays.
- **Export CLI Command**:
  - Introduced `ads llm export [session-name] --format [semantic|json|raw]`.
  - Allows external orchestration tools to directly pipe optimally-formatted session history to their own LLMs seamlessly.
