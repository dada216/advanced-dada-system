# Advanced Dada System v5.4.0 (Red Panda)

## Improvements & Feature Additions

- **Advanced Search Filtering**: Introduced new flags for the `search` subcommand (`--input`, `--output`, and `--tag`) to dramatically narrow down search results and optimize queries.
- **Literal String Searches**: Modified the search parser by bypassing Cobra's strict default flag parsing. The CLI now gracefully accepts special characters, flags, and dashes wrapped in double quotes as literal string searches (e.g. `ads search "--update"`).
- **Directional Database Constraints**: Integrated logical filtering by IO direction mapping straight into the SQLite query execution, filtering `io_stream.direction = 0` (input) and `io_stream.direction = 1` (output) directly at the database level.
- **Fast Metadata Pre-checks**: Added immediate abort logic if a user supplies a `--tag` that isn't present in the specific database's `metadata` table, skipping intensive Full-Text Search entirely for unrelated databases.
- **Extensive Test Coverage**: Shipped rigorous test matrix extensions into `internal/search/engine_test.go` confirming 5 explicit edge-cases around inputs, outputs, targeted tags, and cross-database querying.
