# v0.3 Implementation Plan: Advanced Dada System (ADS)

**Scope:** Semantic chunking via OSC 133 markers and structured command history.

---

## What v0.3 Delivers

| Feature | Behavior |
|---|---|
| `ads hook bash` | Outputs a shell integration script that users can `source` in their `.bashrc`. It injects `OSC 133` markers around prompts and commands. |
| `command_history` Table | A new table in the session SQLite database that stores structured execution records (command, start time, end time, exit code). |
| OSC 133 State Machine | `ads-recorder` will intercept `\033]133;[A,B,C,D]\007` sequences from the raw stream to build semantic boundaries. |

---

## Implementation Steps

### Step 1: Shell Hook Generator (`ads hook`)
- Create `cmd/ads/hook.go`.
- Implement `ads hook bash` which prints a lightweight `PROMPT_COMMAND` and `PS0` script.
  - Before prompt: `\033]133;A\007`
  - After user hits enter (start of execution): `\033]133;C\007`
  - After command finishes (before prompt): `\033]133;D;{exit_code}\007`

### Step 2: Update Session DB Schema
- In `internal/sessiondb/db.go`, add a new table:
  ```sql
  CREATE TABLE IF NOT EXISTS command_history (
      id INTEGER PRIMARY KEY,
      command_text TEXT,
      start_ts DATETIME,
      end_ts DATETIME,
      exit_code INTEGER
  );
  ```
- Add a Go method to insert and update these rows natively.

### Step 3: OSC 133 Stream Scanner
- Update `ads-recorder` (`internal/ansi` or a new `scanner` package).
- As bytes flow in, detect OSC 133 sequences.
- Track state: 
  - `WaitPrompt`: waiting for `A`
  - `WaitInput`: waiting for `B` (or implicitly gathering input buffer)
  - `Executing`: waiting for `D`
- Buffer the command string typed by the user.

### Step 4: Semantic Integration in Recorder
- Wire the scanner into `cmd/ads-recorder/main.go`.
- As commands finish, write the buffered command string and exit code into `command_history`.
- The raw BLOB stream and FTS dual-write will continue to function exactly as before, with the OSC sequences naturally stripped out by our existing ANSI cleaner!
